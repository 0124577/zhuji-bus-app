## 二、边界场景说明

- **定位失败**：`MapBox.locate()` 返回 null，UI 提示「定位失败，已切换到默认区域」，并用诸暨市中心坐标加载附近站点。
- **地图 SDK 不可用 / 未配置 Key**：自动降级为「地图暂不可用，已切换为附近站点列表」，站点列表与所有查询功能不受影响。
- **站点搜索无结果**：弹层显示「没有找到相关站点」。
- **无直达线路**：算法自动降级到 1 次 / 2 次换乘；如确实无方案则显示友好提示。
- **网络异常**：公告与查询均 try/catch，显示错误提示，公告页提供「重新加载」按钮。
- **起终点相同**：提示「起点和终点相同，请重新选择」。
